# 行为契约（behavior-contract）

> 第 0 步产出（无专家路径的业务真相代理）：**一页**，写系统今天实际做什么——不是写它应该做什么。
> 每条标来源：`test:`（现有测试断言）/ `commit:`（git 历史）/ `probe:`（运行实测）/ `unverified:`（推断）。
> 拿去找人确认的是这一页，不是 50 页设计。确认栏填齐 = 业务真相已确认；确认不了 = 留空，
> 并在 gate.md 记录「业务真相未经人工确认」→ 第 4 步裁决上限锁定 Go with Gaps。
> 工件链：上游 ← 测试 / git log / 运行行为（第 0 步收集）｜下游 → gate.md（真相条件）＋ anchors.md（unverified 项重点核查）。
